# Keel

> **Keel（龙骨）— 贯穿项目全生命周期的 Project Harness 工作流。**
> 基于 [Comet](https://github.com/rpamis/comet) Native 运行时，承载 [Atlas](https://sunwenzhe-git.github.io/atlas/) 原创的 Project Harness 治理体系。

## 是什么

Coding Agent 有 Agent Harness，而项目全生命周期更需要 **Project Harness**：应然资产先行、机器严格对账、人机协同终验。

Keel 是一个全新的全流程 AI 编程工作流：

- **运行时底座**：Comet Native 模式（Shape → Build → Verify → Archive，Builder/Verifier 身份分离，状态持久化 + 可恢复归档）。
- **治理层**：Atlas 的三环资产（structure / prd / e2e）、机器门禁（atlas_check）、E2E 评审台、变异证明，下沉为 Native 工作流中的资产与门禁环节。
